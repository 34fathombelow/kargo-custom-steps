# deprecated-apis

Blocks a promotion when the manifests about to be deployed use Kubernetes APIs that the target cluster's version
has removed (or, optionally, deprecated). It catches "works in staging, breaks after the prod upgrade" before Argo CD
tries to sync. Uses [Fairwinds pluto](https://github.com/FairwindsOps/pluto).

## Prerequisites

Beyond the [common prerequisites](../../../../README.md#prerequisites):

| | |
|---|---|
| Cluster add-ons | None |
| Reachable services | None |
| Accounts / credentials | None |
| Kargo capabilities | None |
| Network egress | None (pluto's API data is built into the image) |
| Inputs | Rendered manifests in the workdir, from an earlier `helm-template`, `kustomize-build`, `jsonnet-render` or `git-clone` step |

## Config

| Key | Type | Required | Default | Description |
|---|---|---|---|---|
| `path` | string | yes | — | Workdir-relative directory of rendered manifests, scanned recursively |
| `k8sVersion` | string | yes | — | Target Kubernetes version: `"1.33"`, `"v1.33"` or `"v1.33.0"`. **Quote it in YAML**: an unquoted `1.30` is the number 1.3 before Kargo ever sees it |
| `failOn` | string | no | `removed` | `removed` blocks only APIs the target version no longer serves. `deprecated` also blocks APIs that still work but are deprecated |

## Outputs

| Key | Type | Description |
|---|---|---|
| `passed` | bool | Whether the promotion may proceed under `failOn` |
| `targetVersion` | string | The normalized version checked, e.g. `v1.33.0` |
| `failOn` | string | The policy applied |
| `removed` | list | `{name, kind, apiVersion, deprecatedIn, removedIn, replacement, file}` for each object using an API removed at `targetVersion` |
| `deprecated` | list | The same, for APIs deprecated but still served at `targetVersion` |
| `counts` | object | `{removed, deprecated}` |

When `passed` is false the step **fails** and the promotion stops. The message lists every offending object and its
replacement API, for example
`REMOVED HorizontalPodAutoscaler guestbook uses autoscaling/v2beta2 (removed in v1.26.0, use autoscaling/v2)`.

## Example

```yaml
steps:
# (after a git-clone of your repository into ./src)
- uses: helm-template
  config:
    path: ./src/charts/my-app
    valuesFiles:
    - ./src/charts/my-app/values-prod.yaml
    outPath: ./out
- uses: deprecated-apis
  as: apis
  config:
    path: ./out
    k8sVersion: "1.33"     # the prod cluster's version
```

**Better: look the version up instead of hard-coding it.** Run [`cluster-version`](../cluster-version) first and pass its
output, so the check follows the cluster through upgrades with nobody updating Stages:

```yaml
- uses: cluster-version
  as: cluster
- uses: deprecated-apis
  config:
    path: ./out
    k8sVersion: ${{ outputs['cluster'].version }}   # inside a PromotionTask: task.outputs['cluster'].version
```

If you do hard-code it, give each Stage its own `k8sVersion` (e.g. a Stage `vars` entry): clusters are often upgraded
one environment at a time.

## Try it

Demo project `custom-steps-manifest-quality` ([kargo/projects/manifest-quality](../../../projects/manifest-quality)) scans
[`demo-fixtures/deprecated-apis/manifests`](../../../../demo-fixtures/deprecated-apis/manifests), which contains an
`autoscaling/v2beta2` HorizontalPodAutoscaler (deprecated in 1.23, removed in 1.26):

|---|---|---|
| `k8s-1-25` | `1.25` | Promotion succeeds; output `counts: {removed: 0, deprecated: 1}` |
| `k8s-1-33` | `1.33` | Promotion fails: `Promotion blocked: 1 removed and 0 deprecated API(s) for Kubernetes v1.33.0` |
| `cluster-version-live` | looked up from the agent cluster by [`cluster-version`](../cluster-version) | Blocked on any supported Kubernetes version (newer than 1.25) |

## Notes

- Read-only and idempotent, so retries are safe.
- pluto's own exit codes are ignored (it also exits non-zero for "replacement API not available in the target
  version"). The step decides from pluto's JSON report and `failOn`.
- Only Kubernetes APIs are checked. pluto's data also covers some add-ons (cert-manager, Istio) at their default versions.
- Tested: harness fixtures in [`test/fixtures/deprecated-apis`](../../../../test/fixtures/deprecated-apis).

# cosign-verify

Verifies that an image carries a valid [Sigstore](https://www.sigstore.dev/) / cosign signature **from the signer you
expect**, and blocks the promotion otherwise. Supports keyless signatures (certificate identity + OIDC issuer) and
key-based signatures.

## Prerequisites

Beyond the [common prerequisites](../../../../README.md#prerequisites):

| | |
|---|---|
| Cluster add-ons | None |
| Reachable services | None |
| Accounts / credentials | Registry credentials only for private images (`username` / `password`) |
| Kargo capabilities | None |
| Network egress | The image's registry, and for keyless verification the Sigstore public-good infrastructure (TUF root at `tuf-repo-cdn.sigstore.dev`) |
| Inputs | Images signed with cosign |

## Image

`ghcr.io/34fathombelow/cosign:v3.1.3`, built from [`docker/cosign/Dockerfile`](../../../../docker/cosign/Dockerfile) and published by this repo's
GitHub Actions:

```dockerfile
# cosign plus a shell and jq, so the cosign-verify step can shape its output.
# The upstream image is distroless (no shell).
# renovate: datasource=docker depName=ghcr.io/sigstore/cosign/cosign
ARG COSIGN_VERSION=v3.1.3
# renovate: datasource=docker depName=alpine
ARG ALPINE_VERSION=3.24.2

FROM ghcr.io/sigstore/cosign/cosign:${COSIGN_VERSION} AS cosign

FROM alpine:${ALPINE_VERSION}
LABEL org.opencontainers.image.source=https://github.com/34fathombelow/kargo-custom-steps \
      org.opencontainers.image.description="cosign for the Kargo cosign-verify custom step"
# openssl reads signer identities (SAN, OIDC issuer) from the signature certificates.
RUN apk add --no-cache bash ca-certificates jq openssl
COPY --from=cosign /ko-app/cosign /usr/local/bin/cosign
# cosign caches the Sigstore TUF root under $HOME/.sigstore.
ENV HOME=/tmp
USER 65532:65532
```

## Config

Set **either** a keyless signer (`certificateIdentity*` **and** `certificateOidcIssuer*`) **or** `publicKey`. The step
refuses to run without one: checking for "any valid signature" would accept a signature from anyone.

| Key | Type | Required | Default | Description |
|---|---|---|---|---|
| `image` | string | yes | — | Image to verify. Prefer a digest reference from Freight: `${{ imageFrom(repo).RepoURL + "@" + imageFrom(repo).Digest }}` |
| `certificateIdentity` | string | keyless | — | Exact signer identity (the certificate SAN): an email, or a CI workflow URL such as `https://github.com/org/repo/.github/workflows/release.yml@refs/tags/v1.2.3` |
| `certificateIdentityRegexp` | string | keyless | — | Regular expression for the signer identity, e.g. `^https://github\.com/org/repo/` |
| `certificateOidcIssuer` | string | keyless | — | Exact OIDC issuer, e.g. `https://token.actions.githubusercontent.com` |
| `certificateOidcIssuerRegexp` | string | keyless | — | Regular expression for the OIDC issuer |
| `publicKey` | string | key-based | — | PEM public key, e.g. `${{ secret('cosign').publicKey }}` |
| `username`, `password` | string | no | — | Registry credentials |

## Outputs

| Key | Type | Description |
|---|---|---|
| `verified` | bool | Whether verification succeeded |
| `image` | string | The image that was verified |
| `digest` | string | The verified manifest digest |
| `signatures` | int | Number of valid signatures |
| `identities` | list | Signers found on the image: `{subject, issuer}` (best effort, from the signature certificates) |
| `logIndexes` | list | Rekor transparency-log indexes of the signatures |
| `links` | list | Links to the Rekor entries on search.sigstore.dev, rendered as links in the Kargo UI |
| `error` | string | Why verification failed (empty on success) |

When verification fails the step **fails** and the promotion stops. `error` (and the step message) give cosign's reason,
including the actual signer when it differs from the expected one.

## Example

```yaml
steps:
- uses: cosign-verify
  as: signature
  config:
    image: ${{ imageFrom('ghcr.io/example/app').RepoURL + "@" + imageFrom('ghcr.io/example/app').Digest }}
    certificateIdentityRegexp: ^https://github\.com/example/app/\.github/workflows/release\.yml@refs/tags/
    certificateOidcIssuer: https://token.actions.githubusercontent.com
```

## Notes

- Verify **by digest**. A tag can be moved to a different, unsigned image after Kargo discovered it.
- Read-only, so retries are safe.
- Works with both the new Sigstore bundle format (cosign v3 default, stored as OCI referrers) and the older
  `.sig` tag format.
- Finding the right identity: run `cosign verify --certificate-identity-regexp '.*' --certificate-oidc-issuer-regexp '.*' <image>`
  once by hand. Never use those wildcards in the step itself.
- Tested: harness fixtures in [`test/fixtures/cosign-verify`](../../../../test/fixtures/cosign-verify).

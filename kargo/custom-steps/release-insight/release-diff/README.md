# release-diff

What changed between the revision a Stage runs now and the one being promoted: the git log between two commits,
optionally limited to some paths, with a GitHub compare link. Rollback-aware: when the promoted revision is older, it
lists the commits being **reverted** instead of reporting "no changes".

## Prerequisites

Beyond the [common prerequisites](../../../../README.md#prerequisites):

| | |
|---|---|
| Cluster add-ons | None |
| Reachable services | The git host (when using `repoURL`) |
| Accounts / credentials | None for public repos with `repoURL`. For private repos, clone with `git-clone` (Kargo's git credentials) and use `repoPath` |
| Kargo capabilities | None |
| Network egress | The git host, when using `repoURL` |
| Inputs | With `repoPath`: a clone from an earlier `git-clone` step |

## Config

| Key | Type | Required | Default | Description |
|---|---|---|---|---|
| `repoURL` | string | one of | — | Repository to clone (blobless, read-only) |
| `repoPath` | string | one of | — | Workdir-relative existing clone, e.g. from `git-clone` |
| `from` | string | no | `""` | Revision the Stage runs now. Empty means first release (shows the latest 20 commits) |
| `to` | string | yes | — | Revision being promoted, e.g. `commitFrom(repoURL).ID` |
| `paths` | list | no | `[]` | Limit the log to these repo paths |
| `maxLines` | int | no | `150` | Cap on log lines; the rest is summarized as `... N more` |

**Wrap revisions in `quote()` in the promotion template**, e.g. `to: ${{ quote(commitFrom(vars.repoURL).ID) }}`. A short
SHA made only of digits (such as `4067264` in akuity/guestbook) is otherwise turned into a number by Kargo's template
engine and arrives as `4.067264e+06`. The step quotes its own inputs too.

## Outputs

| Key | Type | Description |
|---|---|---|
| `log` | string | `<short sha> <subject> (<date>)` per commit, newest first. Author names are left out |
| `commits` | int | Number of commits in the range (before `maxLines`) |
| `rollback` | bool | Whether `to` is an ancestor of `from` (the log then lists the commits being reverted) |
| `firstRelease` | bool | Whether there was no usable `from` |
| `summary` | string | e.g. `4 commit(s) in the repository`, `rollback: reverting 4 commit(s) in public` |
| `note` | string | Extra context, e.g. `previous revision X not found (history rewritten?)` |
| `from`, `to` | string | The revisions that were compared |
| `links` | list | A GitHub compare link (shown in the Kargo UI) when the repo is on github.com |

## Example

```yaml
steps:
- uses: release-diff
  as: release
  config:
    repoURL: https://github.com/akuity/guestbook
    from: ${{ quote(stageMetadata(ctx.stage)?.lastCommit ?? "") }}
    to: ${{ quote(commitFrom('https://github.com/akuity/guestbook').ID) }}
    paths: [public]
- uses: set-metadata          # remember what this Stage runs now, for the next diff
  config:
    updates:
    - kind: Stage
      name: ${{ ctx.stage }}
      values:
        lastCommit: ${{ quote(commitFrom('https://github.com/akuity/guestbook').ID) }}
```

## Try it

Demo project `custom-steps-release-insight` ([kargo/projects/release-insight](../../../projects/release-insight)):

| Stage | Freight | Expected |
|---|---|---|
| `release-dev` | Commits from `guestbook-source` (akuity/guestbook `main`) | First promotion: `firstRelease: true` and the latest commits. Later promotions: the commits since the last one |
| `release-staging` | Freight that passed `release-dev` | The same diff, computed from staging's own last commit |

To see a rollback, create Freight from an older discovered commit in the `guestbook-source` Warehouse and promote it:
the output shows `rollback: true` and the commits being reverted.

## Notes

- Read-only; retries are safe.
- A `from` revision that no longer exists (force-pushed history) does not fail the promotion: the step reports it in
  `note` and shows the latest commits. An unknown `to` fails, since it means the config is wrong.
- Merge commits are skipped, so squash- and merge-based histories read the same.
- Tested against akuity/guestbook: harness fixtures in [`test/fixtures/release-diff`](../../../../test/fixtures/release-diff),
  including the digits-only SHA case.

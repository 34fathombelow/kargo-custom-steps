# manifest-diff

Shows exactly what a promotion changes in the rendered Kubernetes manifests: a semantic
[dyff](https://github.com/homeport/dyff) diff between two render outputs, with a resource-level summary and a
Markdown version ready to show reviewers.

## Prerequisites

Beyond the [common prerequisites](../../../../README.md#prerequisites):

| | |
|---|---|
| Cluster add-ons | None |
| Reachable services | None |
| Accounts / credentials | None |
| Kargo capabilities | None |
| Network egress | None |
| Inputs | Two render outputs in the workdir, e.g. from two `helm-template` or `kustomize-build` steps (current vs. new) |

## Image

`ghcr.io/34fathombelow/dyff:v1.12.0`, built from [`docker/dyff/Dockerfile`](../../../../docker/dyff/Dockerfile) and published by this repo's
GitHub Actions:

```dockerfile
# homeport dyff (semantic YAML diff), built from source: no official multi-arch image.
# renovate: datasource=github-releases depName=homeport/dyff
ARG DYFF_VERSION=v1.12.0
# renovate: datasource=docker depName=golang
ARG GO_VERSION=1.27.2
# renovate: datasource=docker depName=alpine
ARG ALPINE_VERSION=3.24.2

FROM golang:${GO_VERSION}-alpine AS build
ARG DYFF_VERSION
RUN CGO_ENABLED=0 go install -trimpath -ldflags='-s -w' github.com/homeport/dyff/cmd/dyff@${DYFF_VERSION}

FROM alpine:${ALPINE_VERSION}
LABEL org.opencontainers.image.source=https://github.com/34fathombelow/kargo-custom-steps \
      org.opencontainers.image.description="dyff for the Kargo manifest-diff custom step"
RUN apk add --no-cache bash ca-certificates jq
COPY --from=build /go/bin/dyff /usr/local/bin/dyff
ENV HOME=/tmp
USER 65532:65532
```

## Config

| Key | Type | Required | Default | Description |
|---|---|---|---|---|
| `from` | string | yes | — | Workdir-relative file or directory with the current manifests |
| `to` | string | yes | — | Workdir-relative file or directory with the new manifests |
| `failOnChange` | bool | no | `false` | Fail the step when anything changed (e.g. a "this promotion must be a no-op" check) |
| `ignoreOrderChanges` | bool | no | `true` | Ignore reordered list entries and documents |
| `maxBytes` | int | no | `60000` | Cap on the diff text kept in the output, so it stays well under Kargo's 256 KiB output limit |

For a directory, every `*.yaml` / `*.yml` file under it (recursively, sorted by path) is concatenated into one
multi-document stream, so files can be split differently on each side without showing up as changes. Resources are
matched by `apiVersion/kind/namespace/name`.

## Outputs

| Key | Type | Description |
|---|---|---|
| `changed` | bool | Whether anything differs |
| `summary` | object | `{added, removed, modified, unchanged}` resource counts |
| `added`, `removed`, `modified` | list | Resource ids, e.g. `apps/v1/Deployment/guestbook/guestbook` |
| `diff` | string | The human-readable dyff report (no colors) |
| `truncated` | bool | Whether `diff` was cut at `maxBytes` |
| `markdown` | string | `### Manifest changes`, the summary and the diff in a code block, ready to show reviewers |

## Example

```yaml
steps:
# (after a git-clone of your repository into ./src)
- uses: helm-template
  as: render-current
  config:
    path: ./src/charts/my-app
    valuesFiles: [./src/charts/my-app/values-prod.yaml]
    outPath: ./out/current.yaml
- uses: helm-template
  as: render-new
  config:
    path: ./src/charts/my-app
    valuesFiles: [./src/charts/my-app/values-prod.yaml]
    setValues:
    - key: image.tag
      value: ${{ imageFrom('ghcr.io/akuity/guestbook').Tag }}
    outPath: ./out/new.yaml
- uses: manifest-diff
  as: diff
  config:
    from: ./out/current.yaml
    to: ./out/new.yaml
```

## Notes

- Read-only and idempotent.
- dyff reports changes by path (`spec.template.spec.containers.guestbook.image`) and detects Kubernetes resources,
  so renamed or reordered documents don't show up as spurious full-document changes.
- Tested: harness fixtures in [`test/fixtures/manifest-diff`](../../../../test/fixtures/manifest-diff).

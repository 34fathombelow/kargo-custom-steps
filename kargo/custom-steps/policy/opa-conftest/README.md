# opa-conftest

Tests rendered manifests, or any structured config (Terraform, Dockerfiles, JSON, YAML, ...), against OPA/Rego policies
with [conftest](https://www.conftest.dev). `deny`/`violation` rules block the promotion; `warn` rules are reported and only
block with `failOnWarn`. Results come back as structured output, and policies come from either the workdir or a
remote bundle.

## Prerequisites

Beyond the [common prerequisites](../../../../README.md#prerequisites):

| | |
|---|---|
| Cluster add-ons | None (conftest is a CLI) |
| Reachable services | None |
| Accounts / credentials | Only if the policies are private: git credentials for `git-clone`, or credentials embedded in a `policyURL` |
| Kargo capabilities | None |
| Network egress | The `policyURL` host, if you use one |
| Inputs | The files to test (e.g. `./out` from `helm-template`), and policies from `git-clone` if you use `policyPath` |

## Config

Set exactly one of `policyPath` and `policyURL`.

| Key | Type | Required | Default | Description |
|---|---|---|---|---|
| `path` | string | yes | — | Workdir-relative file or directory to test |
| `policyPath` | string | one of | — | Workdir-relative directory of `.rego` files |
| `policyURL` | string | one of | — | Remote policies, fetched with `conftest pull`: `https://...`, `git::https://...//dir?ref=v1`, `oci://...` |
| `namespaces` | list | no | `["main"]` | Rego packages to evaluate. `["*"]` evaluates all of them |
| `dataPath` | string | no | — | Workdir-relative data file or directory, available to policies as `data.*` |
| `failOnWarn` | bool | no | `false` | Also block when there are warnings |

## Outputs

| Key | Type | Description |
|---|---|---|
| `passed` | bool | Whether the promotion was allowed through |
| `summary` | object | `{files, successes, failures, warnings}` |
| `failures` | list | Up to 200 `{file, namespace, message}` |
| `warnings` | list | Up to 200 `{file, namespace, message}` |

## Example

```yaml
steps:
# (after a git-clone of your repository into ./src)
- uses: helm-template
  config:
    path: ./src/charts/my-app
    outPath: ./out
- uses: opa-conftest
  as: conftest
  config:
    path: ./out
    policyURL: git::https://github.com/example/platform-policies.git//conftest?ref=main
```

## Notes

- Read-only and idempotent, so retries are safe.
- `conftest pull --policy <dir>` joins even an absolute `<dir>` onto the current directory; the step works around this.
- Tested: harness fixtures in [`test/fixtures/opa-conftest`](../../../../test/fixtures/opa-conftest), including a remote
  `policyURL` fixture that needs network access.

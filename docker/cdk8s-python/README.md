# cdk8s-python

Node.js, the [cdk8s CLI](https://cdk8s.io), Python and [uv](https://docs.astral.sh/uv/), plus `bash`, `jq` and `yq`, for rendering Python cdk8s apps.

Used by: `cdk8s-synth-python`.

## Build manually

```sh
docker build -t ghcr.io/34fathombelow/cdk8s-python:2.207.73 docker/cdk8s-python
```
